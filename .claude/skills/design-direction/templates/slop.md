# Slop list

Patterns that read as generated, not designed. A line here is a rule for every UI phase.
Add a line when you or a reviewer rejects something. Remove one only when the user says so, and log why.
Machine-checkable ones also go in `slop.rules.json`.

- Purple-to-blue gradients as a default brand look.
- Gradient text on headings.
- Cards nested inside cards; every block wrapped in a rounded shadowed box.
- Vague hero copy ("Supercharge your workflow") and feature grids of three icons.
- Decorative blobs, glow orbs and stock-like atmospheric imagery.
- Emoji used as icons.
- One hue family for the whole interface.
- Describing a feature in the UI when the control could speak for itself.
- Trend applied because it is current, with no reason tied to this product's job.
